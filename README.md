# ReadLess
ReadLess 是一个面向学生与知识工作者的 AI 文档理解平台，支持 PDF、Word、TXT、Markdown 等文件上传，并通过 AI 自动生成全文摘要、核心知识点、考试重点与结构化内容，帮助用户在更短时间内完成阅读与学习。  项目重点优化了移动端体验，支持微信场景下的文件导入与文本粘贴，适用于考试复习、课程预习、办公文档快速理解等场景。ReadLess is an AI-powered document analysis platform designed for students and knowledge workers, supporting file uploads in formats such as PDF, Word, TXT, and Markdown.
